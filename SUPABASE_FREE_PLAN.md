# 📋 Supabase Plan Gratuit - Fonctionnalités Disponibles

## ✅ Fonctionnalités disponibles dans le plan gratuit

### 1. Validation Email ✅ DISPONIBLE

**Oui, c'est disponible dans le plan gratuit !**

La validation email est une fonctionnalité de base de l'authentification Supabase et est disponible dans tous les plans, y compris le plan gratuit.

**Limitations du plan gratuit :**
- Les emails sont envoyés via le service SMTP de Supabase (limité)
- Vous pouvez configurer votre propre SMTP pour plus de contrôle
- Pas de templates d'email personnalisés avancés (mais les templates de base fonctionnent)

**Comment activer :**
1. Dashboard Supabase → **Authentication** → **Settings**
2. Activez **"Enable email confirmations"**
3. C'est gratuit ! ✅

---

### 2. Vérification des mots de passe compromis (HaveIBeenPwned) ✅ DISPONIBLE

**Oui, c'est disponible dans le plan gratuit !**

Cette fonctionnalité est incluse dans tous les plans Supabase car c'est une mesure de sécurité importante.

**Comment activer :**
1. Dashboard Supabase → **Authentication** → **Settings**
2. Activez **"Enable password breach detection"**
3. C'est gratuit ! ✅

---

### 3. Mise à jour PostgreSQL ⚠️ GÉRÉ AUTOMATIQUEMENT

**Les mises à jour sont gérées automatiquement par Supabase.**

Supabase gère les mises à jour de sécurité pour tous les plans, y compris le plan gratuit. Cependant :

**Plan gratuit :**
- Les mises à jour sont appliquées automatiquement
- Vous n'avez généralement pas de contrôle sur le timing
- Les mises à jour critiques de sécurité sont prioritaires

**Plans payants :**
- Plus de contrôle sur le timing des mises à jour
- Possibilité de planifier les mises à jour

**Pour vérifier :**
1. Dashboard Supabase → **Settings** → **Infrastructure**
2. Vérifiez votre version actuelle
3. Les mises à jour sont généralement appliquées automatiquement

## 📊 Limitations du plan gratuit à connaître

### Base de données
- ✅ **500 Mo de stockage** par projet
- ✅ **50 000 utilisateurs actifs mensuels (MAU)**
- ✅ **2 Go de bande passante** par mois
- ⚠️ **Pas de sauvegardes automatiques** (mais vous pouvez faire des exports manuels)
- ⚠️ **Pas de Point-in-Time Recovery (PITR)**

### Authentification
- ✅ **Tous les providers OAuth** (Google, GitHub, etc.)
- ✅ **Validation email** ✅
- ✅ **Vérification des mots de passe compromis** ✅
- ✅ **Rate limiting** inclus
- ⚠️ **Limite de 50 000 MAU**

### Projets inactifs
- ⚠️ **Les projets inactifs pendant 90+ jours peuvent être supprimés**
- 💡 **Solution :** Utilisez votre projet régulièrement ou passez à un plan payant
